# Inza Reference macOS App

Native SwiftUI prototype for a clean, minimal, power-user-oriented Anki interface.

It is a showcase app with static demo data. It focuses on product direction:

- source-list navigation instead of Qt-style window clutter
- dense deck and review state at a glance
- keyboard-first review controls
- native table browsing and note inspection
- AI deck creation as a first-class workflow
- visible scheduler, sync, and compatibility status

Run it from this directory:

```sh
swift run
```

Or open `Package.swift` in Xcode and run the `InzaReference` scheme.
